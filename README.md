# Museum Landing Page

[Visit the Website](https://lishvets.github.io/Museum2) | [View Figma Design](https://www.figma.com/design/HL3XGt5ZatvJoYBhOaWY5x/museum-prototype?node-id=323-1957&p=f&t=zU6ws3pzK6yjHe0C-0)


A modern, accessible, and fully responsive web platform designed for a cultural museum. The site allows visitors to explore current exhibitions, upcoming events, and seamlessly purchase admission tickets online. Built with clean HTML5, modular SCSS, and vanilla JavaScript.

## Project Overview

- **Tech Stack:** HTML5, SCSS, JavaScript
- **Code Organization:** BEM methodology for scalable architecture
- **Performance & Standards:**
  - Fully validated, semantic HTML5 structure
  - Optimized media assets and inline SVG icons for quick loading
  - Flawless cross-browser compatibility with clean CSS resets
  - Responsive layout for mobile, tablet, and desktop viewports
- **Key Highlights:**
  - Accessible navigation and interactive mobile drawer menu
  - Dedicated sections for featured exhibitions, schedules, and ticket booking
  - Smooth visual polish with lightweight CSS animations and interactive states
  - Pixel-perfect adherence to design guidelines

## Development Details

- **Mobile-First Workflow:** Engineered starting from smallest screens up to high-resolution desktops to ensure optimal viewing on any device.
- **SCSS Architecture:** Utilizes nestings, custom mixins, variables, and a split-component folder structure for maintainable code.
- **Modern Layout Techniques:** Built using CSS Grid and Flexbox for stable, fluid component alignment across dynamic content blocks.
- **Custom UI Features:** Includes styled interactive components and custom form elements tailored specifically for event scheduling and ticket purchasing.
